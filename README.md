# A medida · Entrenamiento integral

App instalable (PWA) de registro de entrenamiento, macros y medidas.

- Dirección: https://rmormar19.github.io/amedida/
- Para instalar: abrir la dirección en el celular (Safari en iPhone, Chrome en Android) y tocar «Instalar» en Hoy.
- `fuente/` guarda los archivos con los que se arma la app (no se publican como parte de la app).
